# 🖐️ AI Virtual Mouse – Hand Gesture Control

An AI-powered **Virtual Mouse** built using **Python, OpenCV, and MediaPipe** that allows users to control the computer cursor using **hand gestures**.

The system uses a webcam to detect and track hand movements in real time. Users can move the cursor, perform clicks, and interact with the computer without using a physical mouse.

### 🚀 Features

* Real-time hand tracking
* Hand gesture-based cursor control
* Touch-free mouse operation
* Left-click using hand gestures
* Smooth and responsive cursor movement
* Webcam-based interaction
* Easy to use and lightweight

### 🛠️ Technologies Used

* Python
* OpenCV
* MediaPipe
* PyAutoGUI

### 🎯 Project Objective

The main goal of this project is to create a **touchless human-computer interaction system** that provides an alternative way to control a computer using natural hand movements.

### 📌 Applications

* Touchless computer control
* Accessibility solutions
* Smart interfaces
* Human-computer interaction
* AI/Computer Vision projects
